## ▶️ How to Run the Portfolio

### Step 1: Open VS Code

Open the portfolio folder in **Visual Studio Code**.

### Step 2: Check the Files

Make sure your folder looks like this:

```text
portfolio/
│
├── index.html
├── style.css
├── script.js
├── README.md
│
└── images/
    └── profile.jpg
```

### Step 3: Open `index.html`

Open the `index.html` file in VS Code.

### Step 4: Use Live Server

Install the **Live Server** extension in VS Code.

Then:

1. Right-click `index.html`
2. Select **Open with Live Server**
3. Your portfolio will open in the browser.

## 🌐 GitHub Deployment

You can upload this project to GitHub and publish it using **GitHub Pages**.

Basic Git commands:

```bash

git branch -M main

git remote add origin YOUR_GITHUB_REPOSITORY_URL

git push -u origin main
```

After pushing the project to GitHub, enable **GitHub Pages** from the repository settings to publish the portfolio online.
